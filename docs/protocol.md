# Протокол Mingte MT163 / MT166

Собрано из документов производителя по MT163 и MT166, журналов штатных демо-программ и разбора прошивок MT163 V3.10C и MT166 V3.003.

## Линия

RS-232, 8N1. Компьютер спрашивает, устройство отвечает.

| Модель | Скорость | Пауза между кадрами |
|---|---|---|
| MT163 | 38400 | от 20 мс |
| MT166 | 9600 | от 20 мс |

## Кадр

```
запрос:  02  LenH LenL  CM PM  [данные]       03  BCC
ответ:   02  LenH LenL  CM PM  P|S  [данные]  03  BCC
```

`Len` — байты от `CM` до конца данных, старший первым. `BCC` — XOR всего от `02` до `03`. В ответе `CM PM` повторяют запрос, за ними байт результата `P` (у статуса — байт датчиков `S`).

```
>> 02 00 02 30 30 03 03
<< 02 00 0F 30 30 59 4D 54 31 36 33 20 56 33 2E 31 30 43 03 53
                  Y  M  T  1  6  3     V  3  .  1  0  C
```

Буква «Y» перед версией в демо-программах — это байт результата.

## Ответы

| P | | |
|---|---|---|
| 59 | Y | успешно |
| 4E | N | отказ |
| 45 | E | нет карты |
| 57 | W | карта не там, где нужно |

На команду, которой прошивка не знает, приходит не кадр, а один байт `15` (NAK).

## MT163

| CM PM | Данные | |
|---|---|---|
| 30 30 | | версия, ровно 12 символов |
| 30 31 | | версия, 13 символов (есть в V3.10C) |
| 31 30 | | вернуть карту |
| 31 33 | | забрать в бокс |
| 31 31 | | приём спереди |
| 31 32 | | приём сзади |
| 32 30 | | статус |
| 32 31 | `00`/`01` | возврат по таймауту выкл/вкл |

«Вернуть» и «забрать» отвечают сразу: `Y` значит «принято», механика доезжает после ответа.

Приём карты отвечает только в конце: устройство ждёт карту до 6 секунд, затягивает до 5 секунд, потом присылает `Y` или `N`.

Время возврата по таймауту задаётся настройкой устройства: 3, 5, 10 или 20 секунд.

| Бит S | 1 |
|---|---|
| b6 | карта у датчика Q3 |
| b5 | карта у датчика Q2 |
| b4 | карта у датчика Q1 |
| b3 | идёт приём |
| b2 | идёт возврат |
| b1 | ошибка |
| b0 | карта в позиции чтения |

| CM PM | |

| 30 30 | версия |
| 31 30 | выдать в позицию чтения |
| 31 31 | выдать к окну |
| 31 32 | выдать наружу |
| 32 30 | статус |
| 33 30 | забрать в коллектор |

| Бит S | 1 |
|---|---|
| b7 | накопитель пуст |
| b6 | карта у окна |
| b5 | карта в позиции чтения |
| b4 | карт мало |

У обеих моделей есть ветка `35 xx` для бесконтактных карт, программа её не использует.

## Загрузчик

Обе модели — STM32F103. Загрузчик занимает первые 8 КБ флеш-памяти, прошивка лежит с `0x08002000`. Загрузчик стартует по кнопке сброса на плате и работает на 115200.

```
устройство  318
компьютер   37 46 52 83 44 85 62
устройство  MT318%
компьютер   MT318%
устройство  OK
компьютер   блок: номер (2 байта) + 256 байт + сумма байтов
устройство  !
...
компьютер   FF FF
```

Последний блок добивается `FF`. Сам загрузчик при прошивке не затирается, так что оборванную прошивку можно повторить.
